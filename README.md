# Online Examination System

A web-based examination platform built using Python and Flask that allows students to take MCQ-based tests and view their results instantly.

## Features
- Student name registration.
- Timed multiple-choice examinations.
- Automatic submission and score calculation.
- Instant result and answer review.
- Examination history.
- SQLite database storage.

## Technologies
- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## Installation

```bash
git clone https://github.com/Shivamtripathi78/Online-Examination-System.git
cd Online-Examination-System

python -m venv .venv
python -m pip install -r requirements.txt
python app.py
```

## Usage

Open `http://127.0.0.1:5000` in your browser, enter your name, and start the examination.

## Database

SQLite automatically creates the `exam.db` database and initializes sample MCQ questions.
